# Win11Desk standalone release — test report

## Implemented release

Standalone React/TypeScript + Express application with private MySQL 8.4, custom email/password owner setup/login, Argon2id password hashes, revocable Secure/HttpOnly sessions, CSRF protection, bounded password hashing and login throttling, authenticator MFA with persisted replay protection, offline single-use recovery codes, invitations and owner/admin/operator/viewer permissions.

The admin workspace includes Overview, Installer, Issued commands, Deployment history/details, Presets, Defaults, Users, Activity, Account security and Operations. History shows detected IP, Windows username, masked credential Reveal/Copy, RDP address/file, immutable Created date, current callback stage, byte counters when supplied, heartbeat, terminal evidence, timeline, notes/tags, archive, Trash/Restore and confirmed terminal deletion. The private tracker remains optional. Imported old tracker records never fabricate missing credentials.

Issued installer artifacts and Windows credentials are encrypted with AES-256-GCM. A capability-protected HTTPS POST retrieves the immutable exact script, which the bootstrap checks against its SHA-256 before execution. Delivery expires after 30 minutes. Revocation cannot stop a script already executing on a target. Idempotent generation replays the original command rather than rotating its capability. Batches create separate credentials/commands. The direct d3m0nbox.online ISO is the only default; custom sources remain editable and there is no mirror fallback.

## Important operational limits

- **The dashboard is now deployed on the authorized dedicated VPS and HTTPS domain.** Six migrations, service health, application restart, trusted TLS, public assets and protected admin responses were verified. First-owner account creation remains the user's choice. A full host reboot, production capacity and an off-host backup destination were not tested in this deployment follow-up.
- **No fresh destructive Windows install was performed for this new admin release.** Earlier installer tests successfully authenticated Windows RDP on supplied disposable VPSs. Current auth/history/telemetry/admin changes are covered by fixtures and synthetic end-to-end callbacks; that is not a new external RDP certification.
- Completion requires reported Windows 11 Professional/build/local-RDP-listener evidence. It is not continuous server health, public firewall validation, external Windows-client authentication or usable-desktop proof. First-login privacy/licensing may remain user actions.
- Preflight validates source ISO signature/full digest before second-stage partitioning; the pinned installer then downloads the payload again and checks its actual file before mounting. These are separate transfers. A changing source can fail on the second transfer after partition setup. Keep the supplied static, immutable ISO available throughout installation; do not treat preflight as a transactional rollback or promise that every later failure leaves disks untouched.
- Automatic installation permanently replaces the detected system disk after compatibility checks, with no terminal prompts. Use only authorized disposable/backed-up targets, working provider recovery access and suitable Windows licensing.
- Progress is callback telemetry, not guessed percentage. Missing reports become stale/unknown rather than false success. Existing old scripts do not gain new hooks automatically.
- No email provider is configured. Invitations are manually shared private tokens; recovery uses offline codes. No email reset delivery is advertised.
- Offline key rotation requires an application maintenance window, database + old/new key backups, dry-run, explicit apply and a deliberate `.env` cutover. It is not automatic online key management. Losing the key loses credential decryptability.
- History deletion changes website records, not the remote Windows VPS. Shared command references/credentials are preserved when other runs remain. Minimal tombstones/audit and retained backup copies follow the documented retention policy.
